# Claims and Their Proofs

Every headline claim in this project, mapped to the code that computes it, the test that guards it, the data it reads, and the check anyone can run. Current values live in the JSONs under `docs/data/`, regenerated by the daily Action; prose in the memo is a dated snapshot (November 13, 2026) by design.

Quick checks, in order of strength:

```bash
pytest tests/                                  167 tests across models, analyses, decoder, manifest
python3 analysis/manifest.py verify            every input and output hashes to the committed manifest
python3 run_all.py --no-fetch                  rebuild every number from committed data
python3 run_all.py                             rebuild from fresh DefiLlama data
```

Two caveats we state rather than hide: the on-chain window now spans roughly three chain days and keeps growing, so solver and corridor shares still carry some time-of-day bias; and how much DefiLlama revenue actually reaches the buyback wallets depends on the definition of revenue applied, which supports this project's central finding that the capture rate is policy, not protocol.
